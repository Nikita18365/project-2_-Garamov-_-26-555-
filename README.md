# Primitive DB

## Управление таблицами

Простой инструмент командной строки для управления таблицами и данными.


## Начало работы

Для запуска базы данных выполните следующую команду в терминале:

```bash
database

```


##Поддерживаемые команды

| Команда | Описание |
| --- | --- |
| `create_table <имя> <столбец1:тип> ...` | Создать новую таблицу с указанными столбцами |
| `list_tables` | Показать список всех существующих таблиц |
| `drop_table <имя_таблицы>` | Удалить указанную таблицу |
| `help` | Показать справочную информацию |
| `exit` | Выйти из программы |


## Типы данных

В системе поддерживаются следующие типы данных:

* `int` - целые числа
* `str` - строки
* `bool` - логический тип (`true` / `false`)

> **Примечание:** Столбец `ID:int` добавляется в каждую таблицу автоматически, если вы не указали его самостоятельно при создании.


## Пример использования

```text
>>> Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>> Введите команду: list_tables
- users

>>> Введите команду: drop_table users
Таблица "users" успешно удалена.

```

CRUD-операции

Данные каждой таблицы хранятся в отдельном JSON-файле в директории `data/`.

Добавление записи
```sql
insert into users values ("Sergei", 28, true)
```

> **Примечание:** Поле `ID` указывать не нужно - оно генерируется автоматически.

Чтение всех записей
```sql
select from users
```
Чтение по условию
```sql
select from users where age = 28
```
Для строковых значений используются кавычки:
```sql
select from users where name = "Sergei"
```
Обновление
```sql
update users set age = 29 where name = "Sergei"
```
Удаление
```sql
delete from users where ID = 1
```
Информация о таблице
```text
info users
```

## Декораторы и кэширование

В проекте используются декораторы и замыкания для повышения надёжности и удобства работы базы данных.

## Обработка ошибок

Декоратор `handle_db_errors` централизованно обрабатывает FileNotFoundError, KeyError, ValueError и другие исключения.
Подтверждение опасных операций

Перед удалением записи или таблицы программа запрашивает подтверждение:

```text
Вы уверены, что хотите выполнить "удаление записи"? [y/n]:
```

При вводе `y` операция выполняется. При любом другом ответе операция отменяется.

## Измерение времени

Для операций `insert` и `select` используется декоратор `log_time`.

Пример вывода:

```text
Функция select выполнилась за 0.000 секунд
```

## Кэширование

Для повторяющихся запросов `select` используется кэш, реализованный с помощью замыкания `create_cacher()`.
